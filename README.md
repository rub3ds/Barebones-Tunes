# Barebones Tunes (C++ / SFML)

A simple console music player built with C++ and SFML.
Currently plays and loops a single track, with pause and resume controls.

## Controls
P = pause, R = resume, Q = quit

## Requirements
- C++ and SFML 3 (audio module)
- Your own audio file named Wiishopchannel.mp3 next to the program
  (rename the file or change the filename in main.cpp to use another song)

## Planned
- Play any song by typing its file name
- Song list and a folder scan
- Volume control

## What I learned
